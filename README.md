# 红黄果 Android

红黄果是一款面向 Android 手机的非官方短剧客户端。它将剧集浏览、搜索、收藏与播放整合在一个界面中，提供剧场与 AI 专区。应用读取站点的影片目录与视频资源，并使用原生播放器播放视频；观看前需要确认已达到所在地法定年龄。

## 应用特色

- **快速找剧**：首页展示焦点内容、精选推荐和最近上新；剧场与 AI 专区支持分类浏览、连续加载。可以按剧名搜索，也可以输入 `#标签名` 查找对应类型。
- **顺手的播放器**：支持续播、选集、上下滑动切换剧集或 AI 作品、横滑精细调整进度，以及竖屏和横屏播放。顶部和底部保留系统手势区域；普通播放时透明状态栏常显，全屏时隐藏状态栏，竖屏资源保持竖屏、横屏资源自动横屏，返回时先退出全屏。拖动进度条时可查看目标位置的画面预览。
- **灵活控制播放**：提供 0.5～3 倍速，长按可临时以 2 倍速播放；播放控件收起后仍保留细进度线。
- **红果短剧频道**：内置官方红果短剧入口，可在应用内浏览、选集，并在原生播放器中直接播放公开免费的剧集。
- **代理与网络**：支持自定义 HTTP / SOCKS5 代理地址，可在设置中切换直连与代理，适配不同网络环境。
- **数据管理**：观看历史与收藏保存在本机，支持搜索历史、收藏管理与备份导入导出。
- **保留自己的片单**：观看历史和收藏保存在本机。登录账号后，可将片单同步到云端，在重新安装或换设备后取回；离线时仍可使用本机片单。
- **减少等待**：目录与封面会缓存在设备上，打开页面时先显示已有内容，再在后台获取更新。界面跟随系统明暗主题切换。
- **应用内更新**：设置中可检查新版本；下载的安装包会经过完整性校验，再交给 Android 系统安装。

## 0.2.0 播放体验更新

当前集缓冲充足后，提前静音准备下一集的播放器、首帧与开头数据；切集时直接复用，回到上一集恢复未完成的观看进度。视频片段使用 128 MiB 本地缓存。当前集卡顿、拖动进度或退出播放页时释放待播实例，快速连切时只让最终选集起播。Android 真机回归覆盖播放器复用、续播、快速连切、缓冲与进度预览、缓存和资源释放。

## 安装

应用需要 Android 8.0（API 26）或更高版本。调试包可直接安装使用。

调试包与正式包使用不同签名，不能直接相互覆盖安装。应用内更新适用于使用同一签名的安装包。

## 从源码构建

需要 JDK 17 或更高版本，以及 Android SDK（API 37、Build Tools 36）。在项目目录运行：

```bash
./gradlew :app:assembleDebug
adb install -r ./app/build/outputs/apk/debug/app-debug.apk
```

生成的调试包位于 `app/build/outputs/apk/debug/`，不会提交到源码仓库。

## 项目结构

- `app/src/main/java/`：Android 容器、原生播放、数据与更新逻辑。
- `app/src/main/assets/`：应用内页面与样式。
- `tools/`：图标与资源生成脚本。

本项目是非官方客户端，不隶属于内容站点；影片目录和播放可用性取决于站点服务。
